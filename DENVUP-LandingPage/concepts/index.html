Concepts

Things we are
still working out.

Every studio has work that is not finished. Rather than hide it, this is where it goes — the ideas, the studies and the experiments that are still moving, with an honest note on how far along each one is.

Concepts in progress

  1. 01

    A scroll that knows what you have read

    Pages that quietly rearrange themselves around what a reader has already looked at. The hard part is not the rearrangement; it is deciding when not to move anything.

    In progress Working prototype. The measurement pass is not finished.

  2. 02

    Type that sets itself

    A page that reads the width of its own column and re-sets itself — size, measure, leading — so the text is always the right length. The tension we are still solving is between the comfort of a stable layout and the honesty of a fluid one.

    In progress Works in the type laboratory. The screen-reader ordering is unresolved.

  3. 03

    A navigation that is a map, not a menu

    Instead of a list of links, a diagram of the site you are in, with your position drawn on it. We want it to be readable as a picture and operable as a list.

    In progress The floating journey dock on the home page is a first attempt.

  4. 04

    One field, many pages

    A single generated surface running behind a whole site, re-parameterised per route instead of reloaded — so the background is continuous and the reader never sees it restart.

    Shipped This is the stage behind the page you are reading. Turn its controls in the lab.

  5. 05

    Handover as a working tool

    Every site we build comes with a library of its own techniques, so the next person to open the code can see what the motion is made of, and reuse it rather than reinvent it.

    Shipped Four hundred and eighty catalogued techniques on the home page.

  6. 06

    A site that explains its own motion

    Every animation on this site is listed with a reference, so a visitor can ask "what is that?" and get an answer with a name and a number, rather than a guess.

    Shipped The technique library is searchable, filterable and copyable.

What you will not find here

No client work, because we have not published any and inventing it would be dishonest. No testimonials, awards, statistics or portraits, for the same reason. If we build something worth showing, it will appear here with the client's name on it.
