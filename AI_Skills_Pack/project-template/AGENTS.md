# AI Agent Project Instructions

This repository uses a bundled skill library for task-specific development guidance.

Before making changes, read `DENVUP_AI_SKILLS_PACK/AI_WORKFLOW.md` and search `DENVUP_AI_SKILLS_PACK/SKILL-INDEX.md` for relevant skills. Read the actual skill files and required references before implementation. Follow the verification and reporting requirements in the workflow.

If the skill pack is absent or the current agent cannot access it, report that limitation rather than pretending it was consulted.
